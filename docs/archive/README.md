# docs/archive

Dated build notes, per-module reports, morning handoffs, and working history from the build of
TalbotIQ PMS. These are kept for provenance — they explain **how** each piece was built and
verified — but they are **not** the current source of truth.

For the current state, start with (repo root) `README.md` and `HANDOVER.md`, then the reference
docs one level up in `docs/` (architecture, system design, runbook, AI go-live).
