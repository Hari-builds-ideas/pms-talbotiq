## Summary of recommended backend follow-ups (small, for a clean Module 13)
- **`GET /api/billing/my-features`** (all roles, read-only) — so any UI pre-disables locked premium controls (#6).
- **`GET /api/ai/nudges`** (manager-scoped) — to render the KPI-nudge dashboard tile (#7).
- **Pagination** on any list that can grow large (#1); **a user display-name field** (#10).

None are blockers for design; the screens, states, and data above are complete and
accurate against the current backend.
